About the project

Smart AI-Based Automatic Timetable Generator

Built for the Department of Computer Science.

What the project does

Preparing a college timetable by hand means juggling faculty, classrooms, laboratories and batches across several semesters. This project does it automatically from a single dataset, and checks that nothing clashes.

How it works

StepWhat happens
1. Read the workbookAcademic, Resource, Batches, Faculty and Slot sheets are read and cleaned, and problem rows are flagged.
2. Plan labs, then theoryA Genetic Algorithm places lab blocks first, pairs faculty, then places every theory period.
3. Validate & exportEvery rule is re-checked from scratch, then the master and semester timetables are shown and exported to Excel.

Technologies used

Python · Genetic Algorithm · pandas · openpyxl · HTML · CSS · JavaScript
